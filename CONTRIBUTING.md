# Contributing to Credit Card Fraud Detection - KNN

Thank you for your interest in contributing! Here's how you can help:

## How to Contribute

### 1. Fork the Repository
```bash
git clone https://github.com/YOUR-USERNAME/credit-card-fraud-detection-knn.git
cd credit-card-fraud-detection-knn
```

### 2. Create a Feature Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes
- Follow the existing code style
- Add comments to complex logic
- Test your changes thoroughly

### 4. Commit Your Changes
```bash
git commit -m "Add your meaningful commit message"
```

### 5. Push to Your Fork
```bash
git push origin feature/your-feature-name
```

### 6. Create a Pull Request
- Describe your changes clearly
- Reference any related issues
- Include test results

## Areas for Contribution

- 🔧 **Code Improvements**: Optimization, refactoring
- 📊 **Features**: New algorithms, visualization enhancements
- 📝 **Documentation**: README updates, code comments
- 🧪 **Testing**: Unit tests, integration tests
- 🐛 **Bug Fixes**: Issue resolution
- 📈 **Data**: Better datasets or preprocessing methods

## Code Style Guidelines

- Use PEP 8 style guide
- Add docstrings to functions
- Use meaningful variable names
- Keep lines under 100 characters

## Testing

Before submitting a PR, ensure:
```bash
# Run data exploration
python data_exploration.py

# Run main model
python main.py

# Run predictions
python predict.py
```

## Reporting Issues

- Use clear, descriptive titles
- Provide steps to reproduce
- Include error messages/logs
- Specify your environment (Python version, OS)

## Questions?

Feel free to open an issue for discussions or questions about the project.

---

Thank you for contributing! 🙏
